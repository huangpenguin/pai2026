# 第 4–5 回共用｜ROS 2 桌面环境源码

[docker-ros2-desktop-ai-robot-book-humble](docker-ros2-desktop-ai-robot-book-humble/README.md)是课程 ROS 2 Humble 桌面镜像所对应的构建／启动源码仓库。课件入口见 11.pdf · PDF 第 2、6 页和 13.pdf · PDF 第 6、8–11 页。

保存了固定 commit 的源码与启动文件，**没有下载镜像或启动容器**。仓库源码快照也不等于固定了 Docker Hub 的 `latest` 镜像 digest；日后复现实验需另记录实际使用的镜像版本。

第 4 回包的阅读入口在 [04_ros2_pubsub](../../04_ros2_pubsub/README.md)，第 5 回主线与扩展在 [05_ros2_lerobot](../../05_ros2_lerobot/README.md)。原课程命令、端口与运行前提可对照 [第 11 章](../../../notes_zh_sumed_up/11_ros2_packages.md)及 [第 12 章](../../../notes_zh_sumed_up/12_ros_data_lerobot.md)。

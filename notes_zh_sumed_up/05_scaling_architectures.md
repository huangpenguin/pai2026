## 1. 一套共同骨架：输入如何成为 token，模型如何读取它们

### 1.1 先区分识别、生成与模型规模

**识别（discriminative；識別）**把输入映射成标签或特征，可写作 $p_\theta(y\mid x)$：$x$ 是图像、视频或状态，$y$ 是类别、边界框、分割掩码、深度或嵌入。**生成（generative；生成）**则在条件 $c$ 下生成目标 $x$，写作 $p_\theta(x\mid c)$；例如文本到图像时 $c$ 是提示词，机器人行动生成时 $c$ 是视觉观测与任务指令，$x$ 是未来动作序列。这里的 $\theta$ 表示模型参数；扩散模型常预测噪声 $\epsilon$，流模型常预测速度 $v$，自回归模型直接预测下一个 token。

所以，“理解”和“生成”不是由网络名字决定的，而是由输入、目标和训练损失共同决定。相同的 Transformer 可以用来分类、对比学习、预测下一个文本 token，或接上动作头输出机器人控制。

> 来源：5.pdf · 第 11–13 页。

课件给出的规模时间线是代表性模型的参数量对数图：语言模型包括 GPT-2 1.5B、GPT-3 175B、PaLM 540B、Llama 3.1 405B、DeepSeek-V3 671B；视觉语言模型包括 CLIP ViT-L 约 0.43B、Flamingo 80B、PaliGemma 3B、Qwen2.5-VL 72B、Kimi-VL 16B；机器人模型包括 RT-1 35M、RT-2 55B、Octo 27–93M、OpenVLA 7B、π0 3.3B 与 GR00T N1 2.2B。它是讲义采用的代表性快照，不是完整模型排行榜，也不代表各模型训练数据或能力可直接比较。要读懂差异，应看“如何编码输入、以什么损失训练、输出什么”，不能只比参数量。

### 1.2 CNN、ViT 与 Transformer 的取舍

卷积网络（CNN）通过局部卷积和池化逐层汇聚特征，天然带有局部性与平移等变/近似不变等归纳偏置：小数据时很有帮助，因为模型先验地知道附近像素更相关。视觉 Transformer（ViT）把图像切成 patch token，再用通用 Transformer 处理；它的结构先验较弱，但在足够大的预训练数据与算力下能够学出强视觉表征。ViT 常把图像划成 $16\times16$ 像素块，将每块线性投影为 token，加入位置编码，并可附加一个汇总全图的 [CLS] token。原始 ViT 结果依赖大规模 JFT-300M 预训练，说明弱归纳偏置可由数据规模补偿。

> 来源：5.pdf · 第 13–14、32 页。

> 原课件图仅在 Mac 本地：`assets/05/transformer_encoder_decoder.png`

*图 1｜编码器先在输入序列内交换信息，解码器还通过交叉注意力读取编码器记忆；残差与归一化稳定深层堆叠。下方注意力热图显示，一个词的表示可以引用相距较远的词，因此模型不必依赖相邻局部窗口才能建模长距离关系。原图页码：5.pdf · 第 14 页。*

Transformer（变换器；トランスフォーマー）的典型层由多头注意力（multi-head attention）、前馈网络（FFN）、残差连接（residual connection）和归一化构成。位置编码告诉模型 token 的顺序。与逐步递归网络不同，训练时一层能并行计算多个位置的表示，因此适合大规模训练。编码器—解码器结构中，编码器做双向 self-attention；解码器一方面对已生成前缀做因果 self-attention，另一方面通过 cross-attention 读取编码器输出。

### 1.3 Token 化、嵌入与位置

把不同模态映射成序列，是共同架构的接口：

- 文本通常用子词切分（如 BPE）形成 token；图像用 patch 或视觉 token；机器人动作可以直接量化成离散 token，也可以保留连续动作块。
- embedding 将离散 token 映射成向量；图像 patch 也经线性投影成为向量。
- 绝对正弦位置编码为不同序列位置添加不同波形向量。RoPE（旋转位置编码）则按位置旋转 Query 和 Key，使它们的内积带有相对位置关系；它不是简单地给每个 token 另加一张“位置表”。

因此，同一个 Transformer 主干能跨模态复用，关键是模态专属编码器/投影器把输入变成兼容 token，输出头再把隐藏表示还原成相应任务结果。

> 来源：5.pdf · 第 15、25–26、32、42 页。

### 1.4 Self-attention 的计算与张量形状

设序列长度为 $L$，模型宽度为 $d_{\text{model}}$，输入矩阵 $X\in\mathbb{R}^{L\times d_{\text{model}}}$。每个注意力头把输入投影成 Query、Key、Value：

$$Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V.$$

若每头的 Key 宽度为 $d_k$，注意力权重为

$$A=\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right),\qquad
\operatorname{Attention}(Q,K,V)=AV.$$

$QK^\top$ 的形状是 $L\times L$，每个元素表示一个查询位置对一个键位置的匹配分数；softmax 沿键的位置归一化为权重；$AV$ 对所有 Value 向量加权求和，得到每个位置融合上下文后的表示。除以 $\sqrt{d_k}$ 可避免维度增大时内积过大、softmax 饱和和梯度不稳。多头注意力在不同子空间独立计算，再将各头结果拼接并经 $W_O$ 投影回 $d_{\text{model}}$。

> 原课件图仅在 Mac 本地：`assets/05/self_attention_shapes.png`

*图 2｜自下而上看：输入 token 矩阵 $X$ → 每头的 $Q,K,V$ → 全部 token 两两打分得到 $L\times L$ 权重矩阵 → 用权重混合 $V$ → 拼接多头并投影。图中的 $N$ 即序列长度，不是模型参数规模。原图页码：5.pdf · 第 16 页。*

> 来源：5.pdf · 第 16–17 页。

三种常见注意力的核心公式相同，差别在于可访问的 Key/Value：

- **Self-attention（自注意力；自己注意）**：Q、K、V 均来自同一序列，可让序列内部位置交换信息。
- **Causal attention（因果注意力）**：用掩码禁止当前位置读取未来 token，保证自回归预测时不偷看答案。
- **Cross-attention（交叉注意力；交差注意）**：Q 来自当前要更新的序列，K/V 来自另一段条件序列，例如动作查询读取图像和语言特征，或图像生成器读取文本条件。

### 1.5 深层训练稳定性与推理效率

早期 Transformer 常用 post-norm：子层输出与残差相加后再归一化。大型深层网络更常使用 pre-norm：先归一化子层输入，再把子层结果加回残差通路，使梯度能沿恒等路径传播。LayerNorm 对每个 token 的通道做归一化；RMSNorm 只按均方根缩放。GELU、SwiGLU 等非线性激活控制前馈变换；dropout 与 weight decay 是正则化手段；AdamW 将权重衰减从梯度矩估计中解耦；混合精度降低显存与计算成本。

> 来源：5.pdf · 第 18–21 页。

标准注意力虽能并行，但完整中间注意力矩阵有 $L^2$ 个元素，长序列常受显存读写而非乘加运算限制。FlashAttention 通过分块（tiling）和 online softmax 在片上 SRAM 中计算精确注意力，避免把整个 $L\times L$ 矩阵写回高带宽显存（HBM）；它把注意力中间结果显存需求从 $O(L^2)$ 降到 $O(L)$，但点积计算本身仍是 $O(L^2)$，不是把算法算量变成线性。FlashAttention-2/3 继续优化 GPU 并行调度。

自回归推理每生成一个 token 都会重新读取上下文。KV cache 保存历史 Key 和 Value，避免重复算旧 token，但占用随上下文长度增长。GQA（分组查询注意力）与 MQA（多查询注意力）让多个 Query 头共享更少的 KV 头；KV 量化、滑动窗口也可降低缓存压力。PagedAttention 将 KV cache 按块管理，减轻请求长度不同造成的显存碎片，vLLM 用此提升并发吞吐；课件给出的 2–4 倍是其讲义引用场景中的吞吐量报告，不是任何工作负载上的固定保证。Speculative decoding 让小模型先提议若干 token，再由大模型并行验证，目标是在不改变目标模型接受分布的前提下减少昂贵的大模型串行步数。量化缩小权重数值表示，蒸馏把大模型行为转移到小模型。

### 1.6 Transformer 以外的序列模型

Transformer 的注意力对序列长度有二次复杂度，因此出现了更便宜的长序列替代设计。MLP-Mixer 交替执行 token-mixing（跨位置混合空间信息）与 channel-mixing（每个位置内混合特征通道），完全不用注意力或卷积。线性注意力、RetNet 和 RWKV 采用不同形式的递推或衰减记忆。状态空间模型（SSM）以隐藏状态递推表示长序列；Mamba 让状态更新参数受当前输入影响，选择性保留或遗忘内容，并用硬件感知 selective scan 将序列处理做成线性时间、固定规模递推状态。Mamba-2 改进了与 Transformer 的统一计算视角。Jamba 则把 Transformer、Mamba 和稀疏专家混合起来。

**补充解释：**概括地说，标准 self-attention 直接比较所有位置，灵活但长序列代价高；递推式 SSM 把历史压入状态，内存经济但必须学会哪些历史值得保留；Mixer 用固定位置间混合换取结构简单。它们是不同的计算取舍，并未让 Transformer 在通用大模型中失去主流地位。

> 来源：5.pdf · 第 22–24 页。

## 2. 训练目标：语言、视觉与生成模型

### 2.1 自回归语言模型与后训练

自回归语言模型用前缀预测下一个 token，训练目标通常是负对数似然：

$$\mathcal{L}_{\text{AR}}=-\sum_{t=1}^{T}\log p_\theta(x_t\mid x_{<t}).$$

训练时因果掩码让每个位置只看左侧上下文，但所有位置的下一个 token 可以在一次前向中并行计算；真正生成时，必须先得到当前 token，再将它追加到前缀，逐步生成。Decoder-only 架构之所以常见，是因一个 next-token 目标就能统一续写、问答、示例内学习和多模态 token 预测。

典型后训练包含：预训练（大量文本 next-token）、监督微调 SFT（用示范教指令遵循）、奖励模型（从偏好比较学习标量偏好）以及 PPO 等强化学习（用 KL 惩罚约束策略别偏离参考模型过远）。RLHF 的结构可类比到机器人：把任务成功、安全、人工介入或偏好转为反馈，再调整策略。DPO 直接利用偏好对优化策略；PRM 对推理过程步骤评分；CoT 是显式输出或内部延展推理过程的一类方法。

GRPO（Group Relative Policy Optimization）在同一问题上采样 $G$ 个答案，以组内奖励均值作相对基线，因此不用单独训练 critic/value model。**补充解释：**常见组优势的一种归一化写作 $A_i=(r_i-\bar r)/(\sigma_r+\epsilon)$；不同实现的裁剪、归一化细节会变化，核心是用同题样本的相对奖励代替单独价值网络。RLVR 用可验证奖励训练推理模型，例如数学答案匹配、代码单元测试或编译器结果；当核验器可靠时，不需要训练式奖励模型，客观正误较难被主观偏好绕过。GRPO 与 RLVR 是互补组件：前者给出组相对策略更新，后者提供可程序核验的奖励。

> 来源：5.pdf · 第 25–30 页。

稀疏专家混合（MoE）令 router 按 token 为每个输入选择 top-k 个 FFN expert；总参数可以很大，但每个 token 只激活少部分参数，计算量因而低于同规模稠密模型。若路由过度集中会有 expert 负载不均，常加辅助均衡损失。MoT（Mixture-of-Transformers）则按模态分开 FFN、QKV 或归一化层，同时共享部分注意力空间，属于模态级而非 token 级分治。π0 将视觉/文本主干与动作 expert 分离，体现专用动作分支与共享表征协作的思路；不应把它等同于完全相同的 MoT 实现。

> 来源：5.pdf · 第 27–31 页。

### 2.2 视觉表示：对比、自蒸馏、遮挡重建与分割

视觉模型训练目标不同，学到的表示也不同：

- **CLIP**以图像编码器和文本编码器把配对图文嵌入到共同空间；批次中匹配图文相似、不匹配对相斥的 InfoNCE 对比损失，使模型可用自然语言类别做 zero-shot 分类或检索。课件注明其训练规模为约 4 亿图文对。
- **SigLIP**以成对 sigmoid 损失替换全批次 softmax 对比损失，优化不必依赖全局批次归一化，因此对小批次更友好。SigLIP So400m 是常见的较强视觉编码器；PaliGemma 与 π0 采用该系列特征。SigLIP 2 增加多语言能力。
- **DINO**不需类别标签，以学生网络匹配 EMA 教师网络的表征；stop-gradient、输出 centering/sharpening 和 multi-crop 视图帮助防止表示坍塌。DINOv2 提供可冻结后转移到分类、分割、深度和检索的通用视觉特征，OpenVLA 使用 DINOv2 与 SigLIP 的视觉表征。课件将 DINOv3 描述为使用 Gram anchoring 保持长训的稠密特征质量，并报告 1.7B 图像、最大 7B 参数；这是课件所引版本的规模数字。
- **MAE（Masked Autoencoder）**随机遮住约 75% 的图像 patch，编码器只看可见 patch，轻量/非对称解码器重建被遮区域像素。高遮挡率减少编码器运算，也逼迫模型利用可见上下文。
- **SAM**用点、框或已有掩码作 prompt，重型图像编码器只对图像运行一次，轻型 prompt/mask decoder 生成对象掩码。SA-1B 含约 11 亿掩码。SAM 2 增加流式记忆用于视频提示分割与跟踪；SAM 3 扩至文本或 exemplar 提示的概念实例分割/跟踪；SAM 3D 从单张图像恢复物体或人体 3D 形状。

> 来源：5.pdf · 第 34–40 页。

感知不止 2D 识别：单目或双目深度给出每像素距离；NeRF 与 3D Gaussian Splatting（3DGS）表示可渲染的 3D 场景；SLAM 同步估计相机运动与环境地图；VGGT 从多视图联合预测相机、深度、点图与轨迹；HaMeR 等从 RGB 恢复 MANO 参数化 3D 手网格。它们把视觉输入转换为几何、姿态、接触位置等物理相关状态，可供操作或人类示范理解使用。

> 来源：5.pdf · 第 41 页。

### 2.3 VLM 如何把图像接到语言主干

视觉语言模型（VLM）通常保留语言模型 decoder：图像先经 ViT/CLIP 编码成 patch 特征，再由 connector（线性层、MLP 或 attention pooling）映射到语言 token 的向量空间；图像 token 与提示文本一起送入 decoder，decoder 生成答案 token。若图像 token 排在文本前面，因果掩码允许后续文本看到这些图像特征。训练可先做图像 caption，再做指令微调，并在答案 token 上计算生成损失。

> 原课件图仅在 Mac 本地：`assets/05/vlm_qwen_architecture.png`

*图 3｜视觉编码器把原始图像变为视觉 token，merger/connector 控制 token 数并对齐到语言解码器，时空位置编码用于对齐视频帧和文字。该图是 Qwen2.5-VL 示例，不代表所有 VLM 的内部结构相同。原图页码：5.pdf · 第 45 页。*

课件重点比较了三种 VLM：

- **PaliGemma**：SigLIP-So400m 视觉编码器 + 线性投影器 + Gemma 约 2B decoder，合计约 3B；采用 prefix-LM 思路，图像/提示前缀可双向交互，生成答案时按因果方向解码。适合检测、分割、VQA 与 caption 等迁移任务，也是 π0/π0.5 的语言视觉主干。
- **Qwen2.5-VL**：原生分辨率/动态分辨率 ViT，结合窗口与全局注意力，再通过 merger 接 Qwen2.5 LLM；MRoPE 对齐时间、空间与序列位置。课件列出 3B、7B、72B 规模，强调视频、长文档、GUI、agent、边界框或点等 grounding 能力。
- **Kimi-VL**：约 400M 的原生分辨率 MoonViT、MLP projector 与 MoE 语言解码器；课件列为 16B 总参数、3B active，128K 上下文，支持多模态推理、agent 与 thinking 变体。总参数与激活参数不可混为一谈。

InternVideo3 展示长视频路线：以原生分辨率处理图像、视频和文档 token，采用 Qwen3 系语言主干与压缩 KV（M²LA）处理长上下文，并通过证据累积和核验处理长视频问答。课件列出 Video-MME、MLVU、EgoSchema 等基准与 8B 开放版本；这些是课件对特定发布版本的描述。

> 来源：5.pdf · 第 33、42–46 页。

### 2.4 扩散与流：从噪声生成连续样本

VAE 将数据压进连续潜在变量；VQ-VAE 将其量化到离散 codebook。GAN（生成对抗网络）用生成器与判别器对抗训练，BigGAN 展示了高质量大规模生成，但对抗优化容易不稳定。扩散与流模型通过更直接的去噪/速度回归目标，成为可扩展生成路线；Rectified Flow 试图把源到目标的运输路径变直，以少量积分步生成样本。

DDPM 先逐步向数据加噪，再学习反向去噪。把干净样本记作 $x_0$、噪声为 $\epsilon\sim\mathcal{N}(0,I)$、扩散时刻为 $t$，噪声日程的累计保留系数为 $\bar\alpha_t$，则

$$x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\epsilon.$$

训练时让网络从 $x_t,t$ 预测添加的噪声：

$$\mathcal{L}_{\text{DDPM}}
=\mathbb{E}_{t,x_0,\epsilon}\!\left[
\left\|\epsilon-\epsilon_\theta(x_t,t)\right\|_2^2
\right].$$

推理从随机噪声出发，多步调用去噪器逐渐回到数据分布。$x_t$ 是中间噪声样本，$\epsilon_\theta$ 是模型估计噪声；训练样本可由解析加噪直接构造，不必真的串行模拟每一步扩散。

> 原课件图仅在 Mac 本地：`assets/05/ddpm_forward_reverse.png`

*图 4｜左侧前向过程逐渐丢失样本细节、接近高斯噪声；右侧反向过程以学习到的噪声预测器逐步恢复图像。训练常随机采样时刻 $t$，推理才按离散时间步迭代。原图页码：5.pdf · 第 49 页。*

Conditional Flow Matching（条件流匹配，CFM）学习一个随时间变化的速度场，把源分布样本运到目标数据分布。课件采用直线路径：源噪声 $x_0$、目标样本 $x_1$、$t\in[0,1]$，

$$x_t=(1-t)x_0+t x_1,\qquad u_t=x_1-x_0,$$

$$\mathcal{L}_{\text{CFM}}
=\mathbb{E}_{t,x_1,x_0}\!\left[
\left\|v_\theta(x_t,t)-u_t\right\|_2^2
\right].$$

网络预测 $v_\theta$，训练时回归已知的目标速度 $u_t$；生成时从噪声初始化，数值积分常微分方程 $dx/dt=v_\theta(x,t)$ 到 $t=1$。这里 $x_0$ 是源噪声，不是“零值向量”；$x_1$ 是目标数据样本。直线路径是讲义用于解释的条件耦合，不应误解为所有扩散采样轨迹都严格直线。

> 原课件图仅在 Mac 本地：`assets/05/flow_matching.png`

*图 5｜流模型把源样本与数据样本之间的路径看成连续运输，并训练局部速度；少量 ODE 步即可把噪声沿速度场推向数据。原图页码：5.pdf · 第 50 页。*

> 来源：5.pdf · 第 47–50 页；第 55 页将语言、图像与动作的共同骨架总结为“输入 token/patch、共享 Transformer、按任务选择识别或生成目标”，其要点已在前述各节展开。

潜在扩散模型（LDM）先用 VAE 压缩图像，再在低分辨率潜在空间去噪；文本通过 cross-attention 输入 U-Net，最终由 VAE 解码回像素。这样把压缩与生成分开，降低高分辨率生成成本。视频 DiT 在视频 VAE 的时空潜在 patch 上做扩散 Transformer，可处理不同分辨率、长度和宽高比；课件以 Sora、Veo、Wan、CogVideoX 作发展实例，相关版本及服务状态属于课件发表时期的记录。DreamFusion 用二维扩散模型提供的分数蒸馏采样（SDS）梯度优化 NeRF，实现没有配对 3D 训练数据时的 text-to-3D；3DGS 与 LRM 是另一类 3D 重建/生成路线。人体动作生成中，MDM 以扩散生成动作，MLD 在运动潜在空间中生成以提速，OmniControl 允许指定任意关节在指定时刻/空间位置的约束；它们与机器人 VLA 不同，但可用于 humanoid 动作先验与 retargeting。

> 来源：5.pdf · 第 51–54 页。

## 3. Scaling：同时增加模型、数据、推理计算与多样性

### 3.1 训练计算的三变量关系

经验缩放律常将验证损失近似为模型参数量 $N$、训练数据量 $D$ 和训练计算量 $C$ 的平滑幂律函数。对数坐标下损失随资源增加近似线性下降，使得试验结果可用于预测扩大训练后的收益。课件所引 Kaplan 图中的单变量拟合示例分别为 $L=(C_{\min}/(2.3\times10^8))^{-0.050}$、$L=(D/(5.4\times10^{13}))^{-0.095}$ 与 $L=(N/(8.8\times10^{13}))^{-0.076}$；$L$ 是测试交叉熵损失，$D$ 是 token 数，$N$ 是非嵌入参数数，$C_{\min}$ 为计算效率前沿计算量，以 PF-day 为单位（$1$ PF-day 约 $8.64\times10^{19}$ FLOPs）。**勘误：** 计算量归一化常数在源图为 $2.3\times10^8$，Kaplan 原文为 $3.1\times10^8$，详见[原论文](https://arxiv.org/abs/2001.08361)。归一化常数和指数属于特定训练/数据设定，不能直接当作所有模型的通用公式。Kaplan 等早期结论和 Chinchilla 的 compute-optimal 分配回答的是不同问题：前者刻画损失如何随资源变化，后者讨论固定计算预算应如何在参数和数据间分配。讲义给出一个方便记忆的规则 $D\approx20N$ token，但它是特定训练设定下的量级经验，不是跨模型、数据质量和训练时长都精确成立的定律。模型太大而 token 不够会 undertrain；增加数据时，算力和模型容量也必须配平。

### 3.2 三条可扩展轴与三类瓶颈

课件把 Physical AI 的 scaling 分成三个互补轴：

1. **训练时规模**：增加模型 $N$、训练数据 $D$ 与计算 $C$。瓶颈是高质量数据枯竭和资源分配。
2. **推理时计算**：给模型更多 test-time compute，例如 CoT、自洽性多采样或搜索，增加“思考 token”来改善答案。R1/o 类推理模型通过强化学习学会延长推理。物理控制要考虑硬实时边界；50Hz 控制周期只有 20ms，120Hz 只有约 8.3ms，无法无限延长逐 token 推理。
3. **环境与 embodiment 多样性**：增加训练地点、任务、机器人形态与动作空间。跨环境与跨身体的覆盖能提高泛化，但采集、标注和动作映射成本高。

高层决策可以低频“想”，底层动作必须及时完成，因此常把长时推理与快速动作控制分成双系统或层级策略。看 scaling 时，不能只看参数数目，还应问训练数据覆盖了哪些环境、任务和身体。

> 来源：5.pdf · 第 57–64 页、第 89 页。

Emergent ability 图常显示某些任务能力在规模到达门槛后突然跃升；但 exact-match 一类离散指标会把连续改善压成“0 到 1”，制造突变观感。用对数似然或编辑距离等连续指标看，性能可能更平滑。因此既不应断言所有涌现都是错觉，也不能仅凭阈值图就推断能力发生了真正的不连续相变。

### 3.3 机器人缩放证据、重复数据与迁移限制

课件用 GEN-0 和 TRI Large Behavior Model（LBM）展示机器人任务上的缩放证据。GEN-0 衣物操作验证误差随预训练轨迹数量 $D$ 的拟合式为

$$L=7.82\times10^{-2}D^{-0.05}.$$

课件图中数据从 51.2M 到 1B 轨迹，显示误差随数据量缓慢下降；相应实机实验中，预训练数据增加时成功率从 0% 提升至 57%，每项任务仅用约 5.6 小时 post-training；使用全部 post-training 数据的汇总值标为 79%。这些是该项目特定任务和实验设置的曲线，不能据此断言任意机器人任务都会遵循同一个指数。

> 原课件图仅在 Mac 本地：`assets/05/gen0_data_scaling.png`

*图 7｜左图验证误差对轨迹数的幂律拟合，右图为随预训练数据份额增加的实机成功率。注意右侧柱子带有误差区间，数据集大小比例之外还包含固定 post-training 条件；这支持该设置内的数据迁移趋势，不直接证明所有场景因果相同。原图页码：5.pdf · 第 65 页。*

GEN-0 的另一页比较模型规模和训练计算：1B 模型出现“ossification”（骨化，即模型容量不足以继续吸收新增数据而曲线恶化），6B 逐渐饱和，7B 仍持续改善。这个现象说明在数据规模扩大后，容量约束可能显现；数字是课件引用研究的特定实验结论，不能普遍外推为“7B 是机器人模型的普适临界点”。

多样性也能成为缩放变量：π0.5 的课件结果显示，训练地点数增多有利于开放环境泛化，约 100 个环境时某些结果接近同域训练；embodiment scaling 工作则通过程序生成不同身体形态，观察到形态多样性上升时对未见机器人零样本转移改善。这里“100 个地点”和趋势都是各自论文的设置，不是通用门槛。

数据受限模型重复训练同一数据时，边际收益会下降。课件引述语言模型结果：约 4 个 epoch 内重复数据的效用仍可接近新数据，约 40 epoch 后价值很低。机器人数据更稀少，因此实践组合包括去重、质量过滤、课程学习、有限重复与合成数据；应将其理解为可选手段，而非保证提升的通用配方。

> 来源：5.pdf · 第 64–68 页；第 69 页归纳上述三条轴与数据、延迟和收集成本这三类壁垒，已并入本节总结。

## 4. VLA：把视觉语言表征接到动作上

### 4.1 统一解剖图：backbone 与 action head

视觉—语言—行动模型（VLA）常可分为共享视觉语言主干和动作头。输入包括摄像头 RGB/RGB-D、任务指令/子目标/历史信息，以及机器人状态（关节角、夹爪、末端执行器姿态）；状态经线性投影变成 token，与视觉/语言 token 一起编码。共享 VLM backbone 形成条件特征，动作头再输出离散 action token，或连续动作块。

> 原课件图仅在 Mac 本地：`assets/05/vla_anatomy.png`

*图 8｜观测、文字任务和机器人状态先对齐到共享 token/特征空间，再由不同动作头分流。读一个新 VLA，先看它用何种 backbone，再看 action 如何表示、以什么频率输出，以及动作块有多长。原图页码：5.pdf · 第 71 页。*

两条典型输出路线如下：

- **离散/文本 token**：把连续动作维度量化，例如分成 256 个 bin，序列化后复用语言模型的 LM head 与自回归解码。优点是直接利用成熟的 token 训练框架；缺点是多维动作变长序列、量化误差与串行延迟可能变大。
- **连续 diffusion/flow action expert**：直接建模连续动作块，适合高 DoF 或复杂的多峰动作分布。动作头可通过 backbone 的 KV 特征获得视觉语言条件，再用去噪或 ODE 积分生成一段动作。它减少逐动作维度 token 解码，但要在有限控制周期内完成采样。RT-2/OpenVLA 常沿用 causal mask；π0 类块动作解码可用 blockwise-causal mask，使当前动作块互相协同，同时阻止访问未来块。

模仿学习（BC）是基本监督路线；Diffusion Policy 学习从观测到动作块的条件分布；flow matching 学速度场生成动作块。FAST 的流程是归一化动作 → DCT（离散余弦变换）转到频域 → 对系数量化/取整 → 展平 → BPE 压缩成动作 token，减少长序列 token 数；BPE 处理离散符号，不能直接处理未经量化的连续系数。[FAST 原论文](https://arxiv.org/abs/2501.09747)之后可做 offline RL，再在真实部署数据上做 online RL；VLA post-training 与语言模型 RL 在结构上相似，但真实机器人反馈昂贵且安全约束更严。

> 来源：5.pdf · 第 7、70–73 页、第 89 页；第 72 页重列 VLA 发展时间线，第 7 页已用 LLM→VLM→VLA 概括“逐步增加模态”的主线。

### 4.3 控制周期、评估基准与真实世界验证

离散自回归动作逐 token 生成，解码延迟大致随 token 数和每步 decoder 前向次数增加。50Hz 一个动作周期为 20ms；120Hz 为约 8.3ms。即便模型预测正确，只要感知、推理、通信与执行总延迟超过周期，也无法及时控制。FAST 压缩 action chunk，可缓解 token 序列过长；flow/diffusion 一次预测整块动作，只需有限 ODE/去噪步骤。常见折衷是约 10Hz 的高层语言/视觉推理配合 50–120Hz 的低层动作系统。

> 来源：5.pdf · 第 89 页。

仿真基准的任务覆盖和可复现性很重要，但结果不能自动等价于实机可靠性。LIBERO 原始四组为 Spatial、Object、Goal、LIBERO-100，共 130 个任务，用于评估终身学习与知识迁移。**勘误：** 源页脚注将第四组写成 long，与图中 LIBERO-100 不一致；LeRobot 则将 LIBERO-100 拆成 90 与 Long 10，于是有五套件。分组口径见[第 1 章](01_physical_ai_robotics.md#62-libero-的任务套件)。SimplerEnv 强调与实机结果的相关仿真评估；RoboArena 等采用分布式真实机器人评估，以减少某一实验室环境偏差。

Real2Sim 试图用少量真实视频构建可用数字孪生。PolaRiS 从场景视频重建 2D Gaussian Splatting/mesh 与可动机器人；SimFoundry 从单段视频生成可用于训练评估的数字场景，并扩展对象、环境和任务近邻。它们能在实机 rollout 前比较策略、做回归测试或筛候选，但模拟器必须与实机任务结果相关。真实评估需要多次试验、不同 seed、成功率和置信区间，并控制硬件个体、环境、初始状态与操作人员差异；试验数少会让均值不稳定。安全与硬件成本尤其限制长时程任务。

> 来源：5.pdf · 第 90–93 页；第 93 页对“VLM backbone + action head、动作表征、后训练、数据与评估”的总结已合并到本节。

## 5. World Model：让策略在内部预测后果

### 5.1 World model 与 world-action model 的边界

World model（世界模型）将动作视为外部策略给定的输入，学习环境如何变化：

$$p_\theta(s_{t+1}\mid s_t,a_t),$$

也可同时预测未来观测 $\hat o_{t+1}$、奖励 $\hat r$ 或成败。这里 $s_t$ 是状态，$o_t$ 是相机等观测，$a_t$ 是动作，$\pi$ 是模型外部的策略，$\theta$ 是世界模型参数。它回答“采取这个动作后世界会如何反应？”。

World-action model（世界—行动模型，WAM）把动作也作为输出，例如

$$p_\theta(\hat o_{t+1},\hat a_t\mid o_{\leq t},g),$$

其中 $g$ 是任务目标，$o_{\leq t}$ 是截至当前的观测历史。它同时生成下一步环境预测和行为，因而将 simulator 与 policy 合进一个模型，边界靠近甚至融入 VLA。关键分类准则是动作位于条件输入端还是生成输出端，而不是模型是否生成视频。UniSim/Cosmos 一类动作条件化视频生成仍可作为 world model；DreamZero/部分 GR00T N2 路线则把行动和环境预测共同建模，属于 WAM 倾向。

> 原课件图仅在 Mac 本地：`assets/05/world_model_and_wam.png`

*图 11｜上半图动作 $a_t$ 由外部策略提供，world model 根据 $(s_t,a_t)$ 预测后果；下半图模型同时从观测历史和目标生成未来观测与动作 $\hat a_t$。分类时先判断“动作在哪边”，再判断生成器具体用潜变量、像素还是 3D 表示。原图页码：5.pdf · 第 95 页。*

> 来源：5.pdf · 第 95–96 页。

### 5.2 五类研究路线

课件将 2024–2026 的路线整理为“两种用途、五类方法”：

1. **潜在动态与基于模型的强化学习（latent MBRL）**：把高维图像压到潜在状态，在低维空间模拟未来，再训练 actor-critic 或做模型预测控制（MPC）。
2. **视频/WAM**：以动作条件化的视频预测器生成未来画面，可用作交互式模拟器、规划依据或合成轨迹源；动作若也由模型输出，则向 WAM 靠近。
3. **结构化 3D/4D**：预测点轨迹、3D/4D Gaussian、物体结构或接触，强调几何和操作相关状态，而不只追求像素逼真。
4. **忠实评估器**：学习能预测策略在真实任务中成败的模拟环境，以替代一部分昂贵、串行的实机 checkpoint 评估。
5. **共进化/强化学习后训练**：在世界模型内 rollout 更新 VLA，再将新实机数据和失败边界放回模型训练，形成闭环。

DreamerV3 使用 RSSM（Recurrent State-Space Model）学习紧凑状态动态，并在想象 rollout 内训练 actor-critic；论文报告同一配置覆盖 150 多种任务。DayDreamer 展示了约一小时真实交互后让四足机器人学会行走的路线。Iso-Dream 分离可控与不可控视觉动态，减少背景变化对动作相关预测的干扰。V-JEPA 2 先用超过百万小时视频作无动作表征预训练，再以约 62 小时机器人数据训练动作条件预测器，并展示零样本 MPC；核心是预测潜在状态而非逐像素生成视频。

> 来源：5.pdf · 第 97 页。

像素视频路线直接预测 action-conditioned future frames。UniSim 把低层控制、语言与相机操作等不同动作统一成条件，生成未来观察帧，并用学得模拟环境训练 RL/VLA。NVIDIA Cosmos 是以文本、图像、视频和动作条件化的 world foundation model 平台，供模拟、合成数据和规划使用。DreamDojo 以约 44K 小时人类第一视角视频和 latent action 预训练，再经 GR-1、G1、AgiBot、YAM 等机器人数据后训练；课件报告蒸馏后的交互生成可达约 10 FPS。高视觉真实感并不保证动作因果、接触和奖励都正确。

结构化世界模型试图显式保留控制相关信息。TesserAct 从 RGB、depth、normal 等视频重建 4D 场景和动作；ManiGaussian 在 3D Gaussian 表示上学习形变场，预测操作后的多视角场景；ATM（Any-point Trajectory Modeling）先从无动作标签视频预测任意点轨迹，再用少量有动作标签示范训练轨迹引导策略。点轨迹或 3D 几何比单纯视频更接近物体运动，但精确接触、摩擦和力仍难建模。

> 来源：5.pdf · 第 98–99 页。

### 5.3 作为评估器、训练场与数据源的闭环

Interactive World Simulator（IWS）用自动编码器把图像压到潜在空间，再用 action-conditioned consistency model 预测未来；课件报告可 15 FPS、稳定 rollout 超 10 分钟，且模拟策略表现与硬件成功率相关。Veo simulator 以视频预测评估 nominal、分布外（OOD）与 safety 场景。真实任务上的高相关模拟器可用于 checkpoint 筛选和夜间回归测试，但相关性必须在具体任务域中验证，不能把模拟分数本身当实机保证。

World-VLA-Loop 给出数据飞轮：先收集成功和近成功 SANS rollout，让世界模型学习视频与奖励；随后在 world simulator 内用 GRPO 优化 VLA；部署新策略，再回收实机 rollout 更新下一轮模型。near-success 很关键，因为纯成功数据缺少失败边界，纯失败数据又可能学到偏离目标的行为。

> 原课件图仅在 Mac 本地：`assets/05/world_vla_loop.png`

*图 12｜四个阶段顺时针闭合：真实策略 rollout 与人工编程共同收集成功/近成功；用视频、动作块和奖励训练 world model；在模拟器内 rollout 并用 GRPO 更新 VLA；把新策略部署回真实/仿真环境，采集新轨迹再训练模型。这个闭环只有在模拟器能保留与任务相关的因果结构时才有意义。原图页码：5.pdf · 第 101 页。*

WM-first 与 VLM-first 并非简单二选一。世界模型路线主张先从视频与交互学物理，再接动作和语言；VLM 路线能直接继承网络图文知识和语言 grounding，工程上可能更经济。视频基础模型计算昂贵，长期 rollout 的幻觉和误差会累积；VLM 也不自带准确接触物理。视觉上逼真的视频与动作跟随、物理约束和奖励准确是不同评价轴。近期务实用途是把世界模型当模拟评估器、训练场和合成数据源；让它从头取代所有 VLM/VLA 能力则仍是研究问题。

> 来源：5.pdf · 第 100–102 页。

## 6. Physical AI 的数据：规模、身体对应与数据飞轮

### 6.1 为什么机器人数据成为主要瓶颈

LLM 可使用海量网络文本；机器人每条数据要有动作、控制时序、状态和真实环境反馈，采集昂贵且不同机器人之间动作空间不一致。扩大 VLA 的主干而不扩动作监督，会造成模型能力与可用行为数据不匹配。数据量之外还要扩展任务、场景、对象、身体形态和失败状态；同一环境里重复相似轨迹不能替代真正多样性。

比较数据规模时必须注明单位：LLM 以 token、VLM 以图文对、DROID/OXE 以轨迹或 episode、Ego4D 以小时/帧、机器人控制以 action step 计数。讲义将其换算成 10 的数量级以说明差距，不能据此宣称不同模态的每个 token、帧和动作步信息价值相同。

> 来源：5.pdf · 第 61、104 页。

### 6.2 三层 Data Pyramid：数量、成本、身体相似度

数据金字塔把常见来源按三个维度安排：

- **Human/web video（底层）**数量最大、成本低，课件估算约 $10^5$–$10^6$ 小时；包含日常第一视角或互联网 how-to 视频，动作意图丰富但常缺精确机器人动作标签，且人体/相机/手与目标机器人的 embodiment gap 较大。
- **Simulation/synthetic（中层）**可通过并行仿真、domain randomization、视频世界模型或合成轨迹扩充；能覆盖稀有场景，成本低于逐条实机采集，但摩擦、接触、传感器延迟等 sim-to-real gap 会影响迁移。
- **Real robot（顶层）**量较少，讲义估算约 $10^3$–$10^4$ 小时，最昂贵；但其动作定义、闭环控制、摩擦接触和硬件噪声最贴近部署 embodiment，fidelity 最高。

> 原课件图仅在 Mac 本地：`assets/05/data_pyramid.png`

*图 13｜往下数据量增加（左侧箭头），往上成本与机器人 embodiment fidelity 增加（右侧箭头）。底层人类视频提供广覆盖，中层仿真补足可控的交互变化，顶层少量真实机器人数据校准动作和接触；三层应形成互补而不是互相替代。原图页码：5.pdf · 第 106 页。*

> 来源：5.pdf · 第 104、106 页。

### 6.3 真实遥操作、公开数据与模拟数据

ALOHA 一类 leader-follower 遥操作中，操作者拖动 leader 机械臂，follower 同步复制，因此能直接记录机器人关节与夹爪动作，标签干净、行为接近执行分布；缺点是需要真实设备、治具和操作人员，一人逐轨迹采集，吞吐昂贵。VR/mocap teleoperation 用头显或运动捕捉获取手腕、手部甚至全身姿态，适于 humanoid，但必须做 retargeting，并面对延迟、操作者熟练度与疲劳。

Open X-Embodiment（OXE）汇总 60 个以上数据集、22 种 embodiment，约 100 万以上真实轨迹，以 RLDS 组织，目标是让多机器人、多场景数据能共训并促进跨身体迁移；RT-1-X/RT-2-X 是这类跨 embodiment 训练的例子。DROID 提供约 76,000 条、约 350 小时的轨迹，来自 564 个场景、86 个任务和 13 个机构；标准化 Franka、立体相机与腕部相机，兼顾统一硬件接口和 in-the-wild 环境多样性。

模拟/合成可填补金字塔中层。课件列 GR00T 使用真实/人类数据抽取 latent action，再生成 dreamed trajectory，提供约 780K 模拟轨迹；Isaac Sim/Isaac Lab 以 GPU 并行物理模拟扩展训练。Cosmos、UniSim 等生成视频/交互环境也可供规划、评测和合成，但最终仍须用实机数据检验迁移。

> 来源：5.pdf · 第 105、107–109 页。

### 6.4 从人类视频到机器人动作：桥接 embodiment gap

Ego4D 汇集约 3,670 小时第一视角日常视频，EPIC-KITCHENS 聚焦厨房活动。此类视频对手—物体相互作用、操作意图和任务阶段提供丰富视觉线索，但通常没有可直接执行的关节轨迹。Project Aria 等可穿戴设备能同步记录 RGB、多传感器、凝视、手部、3D 点云与轨迹；它们有助于建立人体动作和环境几何，但仍要处理隐私、动作标签、坐标系转换和机器人 retargeting。

SONIC 将人类动作、机器人运动和混合指令映射到统一 token 空间，为 humanoid 全身控制连接动作跟踪与 VLA；ManipTrans 把人类手—物体轨迹迁到灵巧机械手，通过轨迹模仿再加 residual fine-tuning 满足接触约束。全身 humanoid 的映射需要对齐整体姿态和动力学，灵巧手还需显式满足手指接触与物体约束，因此两者的桥接方式并不相同。

> 来源：5.pdf · 第 110–112 页。

### 6.5 UMI/YUBI：让采集设备更接近机器人动作

UMI 使用手持式夹爪，让人像直接操作物体一样完成示范，记录夹爪动作及相机观测，避免每次采集都占用整台机器人的 teleoperation。因为手持装置与机器人末端执行器更相似，获得的 action/observation 更容易映射到实际夹爪，降低 embodiment gap；TRI LBM 也纳入 UMI 数据。

YUBI 是 AIRoA 的手持数据采集延伸：手指对齐的 handheld gripper、VR 6DoF 跟踪，支持双手数据；课件列设备约 319g、开源硬件/软件、海外累计超过 10,000 小时，并提到与丰田和 AIST 协作。它试图将 UMI 式轻型采集变成多地点数据基础设施，而非只依赖实验室机器人。手持装置仍不能完全复现机器人质量、动力学、碰撞与真实接触，采集数据必须与机器人实机回放和校准结合。

> 原课件图仅在 Mac 本地：`assets/05/human_to_robot_retarget.png`

*图 14｜SONIC 把人类动作、机器人动作与混合命令投到统一表示，以支持 humanoid 全身控制；ManipTrans 则强调把人手—物体轨迹转成受接触约束的灵巧手动作。两类系统都需 retarget，但全身运动与指尖接触的约束不同。原图页码：5.pdf · 第 112 页。*

### 6.6 课件提出的研究问题

课件最后提出五类可操作的问题：改变 human、handheld、simulation 与 real-robot 数据配比，测量各自对迁移的边际贡献；建立标准化 sim-to-real 相关性评估并报告置信区间；比较把 world model 与 VLA 分开训练或合成单一动作条件模型；研究 humanoid/灵巧手的 retargeting 与触觉数据；以小型 VLA 做可复现实验，逐步添加数据并测量性能曲线。它们把“模型能否继续变大”转成可检验的数据与评估设计问题。

## 7. 习题：规模化与架构

> 习题参考答案均为根据课件原理推导，Notebook 未提供官方答案键。题目保留全部选项，选项次序与源题一致。

### Q1｜Transformer、token 化与动作生成

**题意：**从下列关于 Transformer、token 化与动作生成的说法中，选出错误的一项。

- **A** Transformer 可用 self-attention 并行计算序列中 token 之间的相关性。
- **B** 图像可用 patch token，文本可用 subword token，动作可表示成量化 token，也可表示成连续 action chunk。
- **C** Self-attention 的核心是用 Q 与 K 的内积形成权重，再对 V 做加权求和。
- **D** VLM 可把图像 token 接到 LLM token 序列中，从而扩展成 decoder-only 架构。
- **E** VLA 的 action head 总是像 LLM/VLM 一样用离散 token 生成动作。

**相关知识与提示：**不同模态常共享 Transformer 主干，但输出表示不同；检查选项 E 的“总是”是否符合连续控制模型。对应知识见本章第 1 节和第 4 节。

**参考答案（推导）：E 错误。** VLA 可以用离散 token，也可以用 diffusion/flow action expert 直接生成连续动作块；π0、GR00T 即属连续动作路线。其余选项均描述了课件中的 token 化、注意力运算和 VLM 接入方式。

- **A 正确。**对一个已构造出的序列，QK 相似度矩阵及各位置表示在训练前向中可并行计算；“并行”不表示自回归推理可以一次生成整个未知未来。 可并行计算的是给定输入中的位置关系，并不是突破生成顺序依赖。
- **B 正确。**文本、图像与机器人动作的编码方式可不同；连续动作块不必离散量化。 例如图像的局部块、一个子词和一段连续动作都能接入共同主干，但对应的输出头与损失不同。
- **C 正确。**注意力权重来自缩放后的 $QK^\top$，softmax 后乘 $V$，本章公式给出了完整维度。 Value 提供实际被混合的内容，Key 用于匹配，Query 指定当前位置要寻找的信息。
- **D 正确。**图像编码器与 connector 可把图像 patch 特征映射到语言模型表示空间，再由 decoder-only 主干读取。 这一步改变了输入模态，主干仍可按下一 token 目标生成回答。
- **E 错误。**连续值动作块可由扩散或流模型生成；VLA 不限于离散 token 头。 连续动作还避免逐维量化误差，但多步采样的计算成本需纳入控制延迟。

### Q2｜缩放律与 Physical AI

**题意：**从下列关于缩放律及其向 Physical AI 迁移的说法中，选出错误的一项。

- **A** LLM 缩放中，损失通常随模型规模 N、数据 D 与计算 C 增大而按平滑幂律下降。
- **B** Chinchilla 规律指出，在固定计算量下，模型规模与数据量的分配会影响最优训练结果。
- **C** Physical AI 最好只增加模型规模 N，按只扩模型轴的方式进行 scaling。
- **D** 即使机器人可通过推理时计算获益，控制周期也会给推理延迟设上限。
- **E** VLA/World Model 常受真实机器人数据稀缺与多样数据难以采集的限制。

**相关知识与提示：**区分“已观察到 scaling”与“该增大哪个轴”。固定算力预算下，模型与数据需配平；Physical AI 还多了环境与 embodiment 轴。

**参考答案（推导）：C 错误。** 单独增大 N 会受数据不足、动作空间变化、环境覆盖不足和控制延迟限制。讲义明确将训练计算、推理时计算、多样性列为三条轴，并指出真实机器人数据是重要瓶颈。

- **A 正确。**幂律是经验拟合，在一定数据/模型/优化区间内用于预测损失变化；不意味着所有能力指标都遵循同一公式。 它主要拟合预测损失，不能自动推出每项机器人任务成功率的精确增长。
- **B 正确。**Chinchilla 讨论固定计算预算下的模型与数据分配，较早很多模型因数据不足而训练不足。 若数据太少，大模型不能充分学习；若模型太小，新增数据也可能受容量限制。
- **C 错误。**除模型规模外，训练数据、推理计算、环境和身体多样性也影响性能。 大量相似轨迹还可能缺乏新环境和失败状态，单纯增大模型并不能补齐这种覆盖。
- **D 正确。**50Hz 对应约 20ms、120Hz 对应约 8.3ms 的周期，系统延迟必须纳入设计。 动作块与高低频层级架构可缓解时延，但仍需计算整个感知—执行链的延迟。
- **E 正确。**机器人交互轨迹昂贵且不易跨 embodiment 共享，是课件强调的 scaling wall。 不同机体的动作维数与含义不一致，新增数据还需要做好接口对齐。

### Q3｜VLA 组成与 action head

**题意：**从下列关于 VLA 基本结构和动作头的说法中，选出错误的一项。

- **A** 主要 VLA 接收观测、语言指令与机器人状态，并通过 VLM backbone 和 action head 转成动作。
- **B** 离散/text-token 路线可复用 LLM 自回归生成机制。
- **C** Diffusion/flow 路线适合生成连续 action chunk 或高自由度控制。
- **D** VLA 之间本质差异几乎只有 VLM backbone，动作表示和控制周期在设计上几乎不重要。
- **E** 实机评估对 VLA 改进很关键，但可复现性、统计、成本与安全都是瓶颈。

**相关知识与提示：**比较架构时同时检查输入、动作表征、动作块长度和控制频率。光看 backbone 会漏掉决定延迟与控制精度的关键选择。

**参考答案（推导）：D 错误。** 课件把离散动作 token 与连续 flow/diffusion 视为主要分支，且控制周期直接限制模型能否及时输出。VLA 的差异还体现在训练数据、后训练、层级推理、动作块和评估闭环中。

- **A 正确。**观测、指令和状态经过共同主干融合，再由动作头解码。 具体模型未必使用所有状态字段，应检查实际输入配置，不能只凭 VLA 名称推断接口。
- **B 正确。**量化动作序列可视作词表 token，使用 LM head 逐步生成。 其代价是量化误差和按维度、按时间展开后较长的生成序列。
- **C 正确。**连续生成头可输出整段动作，不必把每个维度拆成离散 token。 训练可表达多个合理动作模式，推理则需要有限步去噪或积分生成样本。
- **D 错误。**动作头和控制节拍直接影响连续性、量化误差、推理时延和机器人可执行性。 相同主干配不同动作表示，可能产生完全不同的延迟和执行精度。
- **E 正确。**实机试验既有信息价值，也受硬件和环境波动、试验数量、安全与费用限制。 只有统一任务、复位条件与成功判据，模型间的性能差异才容易解释。

### Q4｜World Model 与 VLA 的结合

**题意：**从下列关于 World Model 与 VLA 的说法中，选出错误的一项。

- **A** World model 可根据当前状态/观测及动作，预测下一状态/观测或奖励。
- **B** World-action model 把动作也放在输出端，因而与 VLA 的边界更近。
- **C** 潜在空间动态在较低维 latent 中 rollout，可带来数据效率或计算效率优势。
- **D** 足够忠实的 learned simulator 有机会用于 checkpoint 选择和回归测试，减少部分实机评估。
- **E** World model 的主旨是生成漂亮的动态视频；作为策略评估器、训练场或合成数据源都受限，因此用途不大。

**相关知识与提示：**定义 world model 时看动作是条件输入还是预测输出；评估学得模拟器的价值时看它是否复现与任务成败有关的因果变化。

**参考答案（推导）：E 错误。** 课件强调 world model 可用于模拟 rollout、策略训练、真实评估代理、checkpoint 筛选和合成数据。视频逼真并不足以证明物理忠实，但这并不等于评估和训练用途无价值，关键是先验证与实机结果的相关性。

- **A 正确。**典型形式是 $p_\theta(s_{t+1}\mid s_t,a_t)$，还可预测观测与奖励。 动作作为条件能够区分同一场景下不同操作产生的后果。
- **B 正确。**WAM 将未来世界预测和动作一并建模，因此靠近 VLA 的动作输出接口。 应进一步检查是否联合训练、怎样给定条件，以及预测动作如何交给控制器。
- **C 正确。**把像素压入 latent 后 rollout 可降低状态维数与计算量；代价是表示可能丢失对控制重要的细节。 因此 latent 需要保留与任务成功有关的几何、接触与运动信息，而不只是便于压缩。
- **D 正确。**模拟器若对实际任务成败具有经验证的预测相关性，可加速候选筛选与回归测试。 超出已验证任务域时，模型误差可能累积，仍需用实际执行结果重新校准。
- **E 错误。**世界模型的用途不限于画面生成；评估、训练和数据补充都是课件明确列出的方向。其限制是长时预测误差与物理/奖励真实性，而非用途“很小”。 一个不够忠实的模拟器可使策略利用预测漏洞；解决办法是验证与校准，而非否定全部世界模型用途。

### Q5｜Physical AI 数据策略

**题意：**从下列关于 Physical AI 数据的说法中，选出错误的一项。

- **A** Real robot data 的 embodiment fidelity 高，但采集成本高、规模有限。
- **B** 只靠 leader-follower 或 VR teleoperation，就能低成本收集到足够多的基础模型训练数据。
- **C** Data Pyramid 根据数量、成本和 embodiment fidelity 的差异组合真实机器人、模拟/合成与人类/网络视频。
- **D** UMI/YUBI 一类 handheld gripper 旨在以接近机器人动作的形式收集人类操作数据，缩短 embodiment gap。
- **E** 模拟/合成数据易扩量，但接触、摩擦、传感器延迟等 sim-to-real gap 仍要求实机评估或实机数据配合。

**相关知识与提示：**高质量遥操作不等于高吞吐数据；计算“能否规模化”时要计入设备、操作者和每次示范时长。

**参考答案（推导）：B 错误。** 两类遥操作都需要人逐轨迹操作；leader-follower 还需实体装置、VR 则面对 retarget、熟练度、延迟和疲劳。它们适合获得高保真数据，却不能单独解决基础模型所需的数据规模问题。

- **A 正确。**真实硬件和环境提供较高执行保真度，但采集装置、时间和安全成本限制数量。 同时它更接近真实闭环的接触和传感噪声，可用于校准其他数据来源。
- **B 错误。**遥操作吞吐受人力和硬件限制；课件正是以此引出手持采集、仿真和人类视频等互补来源。 采集设备便宜也不能消除每条轨迹的操作、复位和质检时间。
- **C 正确。**金字塔底层量大成本低，中层可控扩增，顶层真实机器人保真度高而昂贵。 组合时应按任务衡量迁移收益，而不是假设来源数量相同就贡献相同。
- **D 正确。**手持夹爪采集具有与机器人末端相近的观测/动作接口，目标是缩小而非彻底消除身体差异。 迁移仍需考虑轨迹可达性、机器人速度限制和实际接触动力学。
- **E 正确。**模拟扩容不能自动消除接触物理、摩擦和传感器模型差异；部署前仍要验证实际迁移。 只有在真实系统上测量最终行为，才能判断这些差距是否已经足够小。
